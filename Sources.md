## 7. Source vs. Assumption Convention

The Excel model distinguishes between:

**External facts**
- Obtained from publicly available sources.

**Model assumptions**
- Values introduced to construct the business case where company-specific information was unavailable.

**Calculated outputs**
- Values generated from Excel formulas using the external inputs and model assumptions.

This distinction is important because the financial outputs should not be interpreted as reported financial results of any company.
